# Support

## Getting help

For a reproducible component defect, documentation correction, or fork-specific enhancement, open a focused [GitHub issue](https://github.com/Alexi5000/terminal-ui/issues). Include the affected component, browser and runtime version, sanitized reproduction steps, the expected behavior, and the observed behavior.

For broader collaboration or agent-interface engineering inquiries, use the contact path at [TechTide AI](https://techtideai.io). This repository is maintained on a best-effort basis. Triage prioritizes broken public contracts, accessibility regressions, and credible security concerns.

## Request routing

| Request type | Route |
|---|---|
| Component behavior, playground issue, documentation defect | Public GitHub issue with a focused reproduction |
| Agent or automation interface design question | Public issue or the TechTide AI contact path, with no private data |
| Vulnerability, leaked secret, or unsafe integration behavior | Follow [SECURITY.md](./SECURITY.md); do not disclose publicly |
| Contribution workflow or review expectation | Read [CONTRIBUTING.md](./CONTRIBUTING.md) and [FORK_POLICY.md](./FORK_POLICY.md) |
| Community conduct concern | Use the private route described in [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) |

Never post credentials, tokens, private prompts, customer data, production logs, or unreported vulnerability details in public channels.
